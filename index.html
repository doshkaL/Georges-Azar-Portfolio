  • 04/2026 – 07/2026AI agent

    VestorVigil AI

    A controlled decision assistant for portfolio risks, built with n8n. It is not a trading bot: it spots risky situations, explains them, and hands critical cases to a person.

    • Pulls live stock data through a Yahoo Finance MCP server; a fixed rule decides whether a case is critical, and an OpenAI model only explains that decision in plain language
    • Critical cases are sent to Discord and wait for Approve or Reject, so nothing happens without a human
    • Analysis, decision and final status are stored in PostgreSQL; all queries are parameterized to prevent SQL injection
    • A chat agent with SQL and MCP tools lets you add trades or check the portfolio value in plain language
    • Tested with manual edge cases and live data; found and fixed a bug in the reject path

    Stack: n8n, OpenAI API, MCP, Yahoo Finance, PostgreSQL, Discord, JavaScript

  • 01/2026Machine learning

    TikTok case study: predicting user verification

    Industry case study from the Google Advanced Data Analytics certificate: predict whether a creator is verified, to help TikTok prioritize user reports.

    • Cleaned a dataset of 19,382 videos with 12 features: removed missing values and capped outliers with the IQR method
    • Only 6.3% of users were verified, so I upsampled the data to balanced classes
    • Added a text length feature and dropped like count because of its 0.86 correlation with view count
    • Logistic regression with 65% accuracy and 84% recall for unverified users; longer videos turned out to be the strongest signal for verified creators

    Stack: Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn
